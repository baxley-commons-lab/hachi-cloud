# SW-001 — Source Well

The constitution. Every other artifact in this system descends from it.

## What this is

SW-001 is not a Grove Card.
SW-001 is not a Notion page.
SW-001 is the repository root of continuity — the constitutional entry point from which every law, card, build sequence, and session draws.

This file plays the same role for the system that `baxley-spec.js` plays for the expression engine: it is the locked source the rest of the system reads before acting.

## Three kinds of truth

The system distinguishes three responsibilities. Each lives in a different place. Do not collapse them.

| Kind | Lives in | Owns | Example IDs |
| --- | --- | --- | --- |
| Repository | this repo | Current executable truth and the constitution | `SW-001` |
| Notion | Notion workspace | Historical reasoning, decisions, relationships | `GC-*`, `LAW-*`, `ARB-*`, `RQ-*` |
| Sessions | session logs, PR history | Implementation events performed against the source | `CC-*` |

## The Descendant Rule (operational root)

Every node in the system must have a parent.
Every parent chain terminates at SW-001.
A node without a path to SW-001 is orphaned and out of system.

The principle is named in `LAW-BC-01 — Descendant Rule`. SW-001 is its operational root: the point at which descent stops.

## Session entry rule

At the top of every Claude Code, Replit, or other AI build session, declare:

- **Source Well:** `SW-001`
- **Repository:** the repo name
- **Related laws:** the `LAW-*` IDs governing this work
- **Related artifacts:** any other Card IDs in scope
- **Files touched:** paths
- **Work performed:** one line
- **Open questions:** if any
- **Next action**

This rule is captured in `GC-SOURCE-WELL-002 — Session Provenance IDs`. SW-001 is the artifact every session begins by declaring.

## Constitutional locks

- Continuity lives in the repository, not the conversation.
- The Source Well does not depend on chat memory, prior sessions, or any tool's UI surfacing the right artifact.
- The repository is canonical for SW-001. Notion records and links to SW-001; it does not own SW-001.
- Sessions are implementation events. They are never the source of truth.
